# Komentář k zákonu č. 104/2008 Sb., o nabídkách převzetí a o změně některých dalších zákonů (zákon o nabídkách převzetí)

Otevřený komentář k zákonu o nabídkách převzetí — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; dobrovolná, povinná a konkurenční nabídka převzetí, nabídkový dokument, protiplnění, pravidlo průlomu, nabídková povinnost, následky porušení a dohled České národní banky.

Konsolidované znění: dokument e-Sbírky `SB-2008-00104_2019-10-01`.
